01 — GAME SERVER

게임 서버 백엔드

개인 프로젝트 · 서버 + Unity 클라이언트

  • 핸들러 자동 등록 — 리플렉션으로 *Handler 클래스의 공개 메서드를 스캔해 POST /{RequestType} 라우트로 매핑했습니다. 새 엔드포인트는 메서드 하나를 추가하는 것으로 열립니다.
  • 트랜잭션 미들웨어 — 요청 하나를 UserDb와 모든 GameDb 샤드에 걸친 트랜잭션으로 묶어, 핸들러가 커밋·롤백을 직접 다루지 않게 했습니다.
  • GameDb 샤딩 — 설정에 선언한 샤드 수만큼 DbContext를 만들고 유저 ID 기준으로 샤드를 선택하는 매니저를 두었습니다.
  • 공유 계약 레이어 — 요청·응답 모델과 MessageId enum을 별도 라이브러리로 분리해 서버와 Unity 클라이언트가 같은 정의를 참조하도록 했습니다.
  • Blazor Server 관리자 패널과 Google Sheets를 CSV 게임 테이블로 내려받는 동기화 도구를 함께 만들었습니다.

02 — VIEWSYSTEM

ViewSystem

Unity UI 프레임워크 · UPM 패키지

  • 스택 기반 뷰 관리 — ViewManager가 레이어별로 뷰를 쌓고 캔버스 sort-order 대역을 나눠 관리합니다.
  • await 가능한 열기 API — ViewRequest.Open<T>()를 await하거나 yield할 수 있고, 제네릭 버전은 뷰가 반환한 결과를 그대로 받습니다. ModalView·PageView·CameraPageView·OverlayView 네 가지 뷰 타입을 제공합니다.
  • 마커 인터페이스 생명주기 — 베이스 메서드를 오버라이드하는 대신 필요한 인터페이스만 구현해 포커스·표시·백버튼 이벤트를 선택적으로 구독하게 했습니다.
  • 포커스·입력 제어 — 한 번의 갱신 패스로 포커스 뷰를 다시 계산하고, 가려진 뷰를 숨기며 레이캐스트 차단을 뷰 단위로 토글합니다.
  • 뷰 프리팹은 타입 이름 규칙으로 Addressables에서 로드하고, 타임스케일과 무관하게 동작하는 UI 애니메이션 재생기를 붙였습니다.
